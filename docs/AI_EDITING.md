# Редактирование документов с ИИ

Комментарий фиксирует вопрос или замечание. Редактор с ИИ готовит конкретное изменение и помогает увидеть его последствия для других документов.

## Подключить свой ИИ

Откройте документ, нажмите «Редактировать», затем раскройте «Мой ИИ · API и модель». Выберите OpenAI, Groq, Cerebras либо другой сервис с API формата Chat Completions. Для другого сервиса укажите базовый адрес API, например `https://example.com/v1`; запрос отправляется на `/chat/completions`. Для локального сервера моделей разрешён HTTP на localhost. Укажите имя модели и свой API-ключ. Если локальный API не требует ключа, оставьте поле пустым.

Ключ сохраняется в локальном файле `data/editor-settings.json`; файл не входит в скачиваемый комплект приложения. Сервер не возвращает ключ в интерфейс или историю предложений. Для встроенных сервисов можно использовать уже настроенный ключ проекта. Сохранение настроек не вызывает модель. API выбранного сервиса используется только после нажатия «Найти связанные правки»; условия доступа и оплаты определяет этот сервис.

Поддерживается формат Chat Completions. Прямые форматы API Claude и Gemini в этой версии не подключены; для них нужен совместимый шлюз или отдельный адаптер. JSON-режим включайте только для сервиса, который его поддерживает. Даже в JSON-режиме программа проверяет структуру ответа и точные цитаты самостоятельно.

## Подготовить и проверить изменение

1. Исправьте русский текст в редакторе или опишите нужное изменение в поле «Что меняем и почему?». Правку можно анализировать до сохранения исходника.
2. Выберите область анализа. Основной документ включается всегда. Краткие инструкции протокола передаются отдельно; полный протокол как материал выбирается дополнительно, если сам не является основным документом. «Показать область анализа» выполняет только локальную подготовку: видно, какие документы передаются полностью, какие — фрагментами, а какие не переданы. Фрагменты выбираются по словам из правки и её описания; это способ поиска, а не доказательство полноты связей.
3. Нажмите «Найти связанные правки». В выбранный API отправляются черновик, описание изменения и указанные тексты. Выполняется один запрос, без автоматических повторов или смены сервиса. Во время анализа документы не изменяются.
4. Просмотрите объяснение каждой связи и «Было → стало». Прямая связь и возможная связь различаются. Отсутствие предложения не доказывает, что зависимость отсутствует. Отдельно видны открытые вопросы и область фактического чтения.
5. Выберите правки и нажмите «Применить выбранные правки». Цитаты должны точно и однозначно совпадать с исходным текстом. Если источники изменились после анализа, применение блокируется. Несовместимые или пересекающиеся правки также не применяются. При изменённом основном документе его правку нужно выбрать вместе со связанными изменениями.

Правки кода показываются для отдельной доработки. ИИ не запускает команды и не переписывает исторические записи о решениях и ошибках; дополнение истории возможно, если прежний текст сохранён. Смысловую оценку и принятие правила выполняет человек.

## После применения

Изменённые Markdown-файлы сохраняются с прежними версиями в `data/source-history/`. Предложение, источники на момент анализа, выбранные и неприменённые правки остаются в `data/editor-changes/`. История доступна из редактора документа.

Английские переводы изменённых русских фрагментов требуют обновления: откройте «Обновить переводы». Они не становятся актуальными по одному факту применения русской правки. Перевод и его связь с текущим оригиналом обновляются отдельно.

В разделе «Ведение памяти проекта» проверьте очередь пересмотра и при необходимости импортируйте новые источники. Старые выводы и результаты опытов не переписываются как будто они получены по новым правилам.

«Отменить это изменение» восстанавливает прежние версии затронутых документов, если после применения в них не появились другие правки. Новые изменения другого автора отменой не перезаписываются. Для возобновления анализа после перезапуска сервера запустите его заново; незавершённый запрос не повторяется автоматически.

Точное совпадение цитат и успешное сохранение подтверждают техническую корректность операции. Согласованность смысла всего протокола ими не доказана.
