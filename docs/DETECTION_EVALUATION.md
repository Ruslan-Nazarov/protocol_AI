# Измерение обнаружения

`protocol_atlas/evaluation.py` вычисляет описательные показатели по явному корпусу. Каждая запись содержит run_id, case_id, cluster_id, происхождение эталона, наличие нарушения, сигнал обнаружителя, допуск, выполнение задачи, времена и стоимость. Неизвестное задаётся null. Повтор одной пары run/case, неизвестный case_id, неверные типы, отрицательные и бесконечные числа отклоняются.

Частота пропусков: пропущенные нарушения / нарушения с известным решением обнаружителя. Частота ложных тревог: ложные срабатывания / корректные случаи с известным решением. Вместе с ними обязательно возвращаются знаменатели, число неизвестных эталонов и решений, охват решений и перечень непройденных случаев. Нулевой знаменатель даёт null.

Задержка — разность времени обнаружения и появления известного нарушения. Длительность вызова проверяющего кода записывается отдельно. Для необнаруженных нарушений и неизвестных времён счётчики сохраняются отдельно, а средняя задержка считается только по наблюдаемым парам. Это не оценка средней задержки по всем нарушениям.

Стоимость содержит известный подытог, число неизвестных записей и полный итог только при полном учёте. В локальном опыте 0 относится только к API; время разработки, CPU и расход этого рабочего чата этим числом не оцениваются.

Корпус `examples/logic/detection-corpus.json` имеет явную версию и заранее записанные эталоны. Их автор — агент; они не названы независимой человеческой оценкой. Эталоны не вычисляются результатом проверяемого обнаружителя. `scripts/evaluate_logic_detector.py --output build/detection-evaluation.json` сохраняет исходные кандидаты, договоры, ответы ядра и расчёт. Корпус не исчерпывает множество ошибок; принадлежность к одному семейству отражена cluster_id.

Доверительные интервалы и уменьшение неопределённости внутреннего применения логики не вычисляются: независимость наблюдений и соответствующее операциональное определение не установлены. `uncertainty_reduction` остаётся null. Рост числа отказов виден отдельно от выполнения задачи.
