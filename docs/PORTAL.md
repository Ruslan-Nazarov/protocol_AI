# Интерфейс протокола

Назначение согласовано с человеком 2026-10-05: протокол и средства его
подключения, понимания, редактирования и улучшения. Рабочие задачи выполняются
во внешнем агенте или чате. Интерфейс не заменяет выбранный рабочий клиент.

Основная навигация содержит четыре раздела:

| Раздел | Действия |
|---|---|
| Протокол | Читать полный текст, раскрывать этапы, редактировать исходник, изучать механику |
| Подключение | Выбрать клиента, подготовить сообщение и скачать архив; локальный API и предварительный профиль не обязательны |
| Результаты и память | Читать состояние, решения, задачи и основания записей этого проекта; видеть устаревшие проверки |
| Улучшение | Разбирать принесённый ответ, оставлять замечания, читать историю и результаты испытаний |

Память рабочего проекта остаётся при нём. Страница результатов явно показывает
происхождение данных; она не собирает автоматически историю внешних чатов.
Записи базы могут относиться к прежним редакциям: статус необходимости повторной
проверки сохраняется. Техническая проверка и принятие человеком показаны отдельно.

В разборе ответа локальный скрипт проверяет отдельные признаки текста. Он не
проверяет весь протокол и не устанавливает фактическое выполнение действий.
Задача, ответ и дополнительные свидетельства могут быть собраны в запрос
для внешнего агента. Запрос содержит версию протокола, требует оснований
замечаний и различает нарушение и отсутствие свидетельств. Подготовка запроса
не вызывает модель; черновик сохраняется только в памяти текущей страницы
между переходами и теряется при перезагрузке.

Прежние редакторы памяти, экспериментальные задачи и стенды доступны внутри
«Улучшение → Инструменты разработки протокола». Они сохраняют свои данные
и возможности, но не входят в основной путь подключения. В самих стендах
возможны платные вызовы при их явном запуске; основные четыре страницы
не запускают модель при открытии.

Проверки интерфейса:

```text
node tests/portal_smoke.cjs
python -m unittest tests.test_catalog tests.test_server tests.test_project_runtime
```

Дополнительно в браузере проверяются чтение и редактор, подготовка подключения
без API, происхождение записей, локальная проверка ответа и подготовка запроса.
