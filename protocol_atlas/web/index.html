Как это работает

Протокол задаёт порядок построения и проверки результатов ИИ. Здесь можно прочитать и изменить правила, понять их механику и подготовить подключение.

Рабочие задачи выполняются в Codex, Claude Code, другом агенте или чате. Память задачи хранится в её проекте. Этот интерфейс показывает сохранённые материалы и помогает разбирать недостатки протокола.

Для чтения, редактирования и подготовки подключения API модели не нужен. Дополнительные функции ИИ требуют отдельной настройки и расходуют API только при явном запуске.
