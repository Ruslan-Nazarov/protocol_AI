# READER — профиль читателя и словарь известного

Правила: `PROTOCOL.md`, этап 1.3.
ИИ читает этот файл в начале сессии, предлагает обновления по сигналам читателя; подтверждает человек.

## Профиль (со слов читателя, 2026-09-28)

| Область | Уровень |
|---|---|
| Программирование | начальный |
| Математика | не уточнён (под сомнением; см. ниже) |
| Философия | средний |
| Художественный язык (родной) | хороший |
| Иностранные языки | начальный |

- Язык: русский
- Стиль изложения: развитие от простого к сложному, без украшений (9.1, 9.4)
- Термины протокола (C, D, вето, хук, трассировка, точка решения, нагрузка, профиль, шаблон, блок и др.): известны, кроме AIMD.

Математика: читатель знает предел, бесконечный ряд, комплексное число, но просит **слегка пояснять** их при использовании (одна фраза напоминания, не полное определение).

## Термины

Термин вне профиля по умолчанию считается **неизвестным** до подтверждения.

| Термин | Статус (известно / введено / неизвестно / под сомнением) | Основание | Дата |
|---|---|---|---|
| термины протокола (кроме AIMD) | известно | заявление читателя | 2026-09-28 |
| AIMD | введено (объяснено 2026-09-28: прибавлять понемногу, при ошибке делить пополам) | ждёт подтверждения | 2026-09-28 |
| предел, бесконечный ряд, комплексное число | известно, с краткими напоминаниями | заявление читателя | 2026-09-28 |
| простое число, составное число, основная теорема арифметики | известно | введены и приняты читателем (шаг принят) | 2026-09-28 |
| гармонический ряд, расходится (ряд), предел последовательности сумм, свойство «возрастающая ограниченная последовательность имеет предел» (как теорема без вывода) | известно | введены и приняты читателем (шаг принят) | 2026-09-28 |
| нуль функции | неизвестно | читатель спросил «что за нули» | 2026-09-28 |
| прочие термины пилота (полюс, аналитическая функция, гамма-функция, критическая полоса, интеграл, модуль числа, логарифм) | считать неизвестными до подтверждения | их нет в профиле (9.3) | 2026-09-28 |

## Сигналы обновления (напоминание)

- «что такое X», «не понял» → X: неизвестно
- «это понятно», «можно короче» → термины этого места: известно
- читатель сам верно употребил X → известно
- поправка читателя к употреблению X → под сомнением
- введён и не вызвал вопросов → введено; в «известно» только после подтверждения читателем
