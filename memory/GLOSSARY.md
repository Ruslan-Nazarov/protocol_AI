## Общие диалектические понятия

Значения взяты из действующих промптов проекта `dialecticalai`: `dialectic_world/prompts/prompt_1.md`, раздел «Основные определения» и выбор кандидата на простейший процесс; `prompt_2.md`, разделы «Основные определения», «Первая итерация» и «Отличие развивающего процесса от внешнего условия». Это общие значения для приложений, использующих данную методологию. В редакции v0.3 эти значения применяются при явном выборе диалектической методологии. Для других задач логика, правила и словарь определяются отдельным договором; исторический словарь не вводит диалектику автоматически.

**Процесс.** Переход одного процесса в другой. Предмет, состояние, свойство или действие раскрывается как процесс через его движение и переход.

**Развитие.** Становление одного из другого: возникающий процесс потенциально содержится в исходном, возникает из достигнутого развития и своим появлением уточняет и раскрывает исходный процесс. Последовательность «сначала одно, затем другое» сама по себе такого становления не показывает. Связь в развитии не обязана быть только временной или причинной: её характер устанавливается по самому предмету.

**Простейший процесс.** Процесс, принимаемый за исходный относительно конкретного рассмотрения. Он одновременно является результатом предшествующего развития и разрешения скачком и исходным процессом для дальнейшего развития, через которое раскрывается его содержание. Его простота означает эту исходную роль; размер, бытовая простота и физическая фундаментальность не определяют его выбор. В промптах выбранный процесс первоначально является кандидатом; окончательное подтверждение требует полного цикла анализа. В протоколе можно работать с обоснованной исходной точкой, не объявляя её окончательно подтверждённым простейшим процессом.

**Развивающий процесс.** Процесс, который вытекает из исходного процесса и уже достигнутого развития, уточняя и раскрывая исходное содержание. На первой итерации каждый следующий процесс учитывает исходный и все уже полученные процессы этой итерации. Практически значимое внешнее условие не становится развивающим процессом только потому, что влияет на предмет.

**Содержательная связь.** Связь, при которой изменение, отсутствие, возникновение или иной характер одного процесса изменяет возможность, характер, ход или результат другого процесса в его реальном осуществлении. Поэтому глубина рассмотрения выбирается по практически значимым для задачи связям.

**Практика.** Реальное осуществление рассматриваемого процесса. Проверка кодом, наблюдение или работа с результатом могут служить способами обращения к практике; её значение не ограничивается сознательной человеческой деятельностью или одним способом проверки.

## Другие термины протокола

| Термин | Значение |
|---|---|
| часть задачи / блок | то, что ИИ берёт в работу за один шаг (в архитектуре раздела 9 — блок) |
| нагрузка | размер части задачи, число 0–12, считается по V+L+H+N (2.2) |
| допустимая нагрузка (C) | граница нагрузки для ситуации, выше которой часть задачи дробится |
| глубина решений (D) | 0–3, насколько глубоко ИИ решает сам без обращения к человеку (2.1) |
| ситуация | (тип задачи, домен, модель) — единица калибровки в `CALIBRATION.md` |
| точка решения | формат, которым ИИ останавливается и передаёт решение человеку (2.4) |
| молчаливая ошибка | ИИ не заметил проблему сам, её нашли позже — самый тяжёлый исход по 2.6 |
